# dev-skills

The skills the Dynamic Agents workspaces install, in the
[Agent Skills](https://agentskills.io/specification) format: the rules for working in a
workspace, the pull-request workflow, and the discovery runs, with the scripts each one runs.

```bash
DISABLE_TELEMETRY=1 npx skills add dynamicagents/dev-skills --skill superproject -a universal claude-code -y
```

[`AGENTS.md`](AGENTS.md) has what each skill is, how to write one, and how a change reaches a
workspace.

Apache-2.0.
